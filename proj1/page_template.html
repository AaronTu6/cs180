01 / The approach

Finding the same scene, three times.

Sergei Prokudin-Gorskii recorded scenes through three color filters, creating separate grayscale exposures. The digitized plates stack blue, green, and red vertically. Because the exposures do not line up exactly, simply assigning them to RGB channels creates colored outlines and doubled details. Collection background ↗

The pipeline divides each plate into three equal-height images, discarding any leftover rows. Pixel values are converted to floats on a common scale. Blue stays fixed; green and red are translated independently to match it. The final array stacks the shifted channels in R, G, B order.

    Split

    Separate the stacked B, G, R exposures.

  2. 02

  3. 03

    Find the best green and red translations.

  4. 04

    Stack RGB and save the color image.

Single-scale search

Try every integer displacement within ±15 pixels along each axis: 31 × 31 = 961 candidates per channel. Shift the moving image, score it against blue, and keep the best offset. This is practical for the small JPEGs, but its displacement range is too limited for many full-size TIFFs.

A coarse-to-fine pyramid

Recursively resize each channel by ½ with anti-aliasing until its largest dimension is at most 400 pixels. Align there with the ±15 search. At each larger level, double the estimate and refine within ±2 pixels, testing only 25 candidates. The final level still uses full-resolution pixels.

Lower is better

L2 distance

√Σ(A − B)²

Measure the difference between corresponding pixel intensities. L2 is simple, but different color channels can have very different brightness values even when their scene details align.

Higher is better

Normalized cross-correlation

Σ(A′B′) / (‖A′‖₂ ‖B′‖₂)

Here A′ = A − mean(A), and likewise for B. Mean subtraction and normalization reduce sensitivity to brightness and contrast differences. Constant regions receive an unusable score because their denominator is zero.

Borders, coordinates, and fixed parameters

Alignment scores use a fixed interior region for all candidates in a search. Each margin is 10% of the image dimension plus the absolute search-center displacement and search radius. This excludes the photographic border and pixels wrapped by np.roll. The same parameter settings are used across all images.

Internally offsets are (dy, dx), matching array rows and columns. Every table below reports (x, y) = (dx, dy): positive x moves right and positive y moves down. These are the shifts applied to green and red, with blue as the reference.

The saved images retain their original borders. Excluding borders from scoring is not automatic output cropping. These results use raw channel pixels with L2 or NCC; no edge features, color correction, or manual per-image offsets are applied.

05 / What works, what remains

Alignment is only part of restoration.

Metric choice changes the answer

On Church, L2 selects red offset (270, 64), while NCC selects (−4, 58). The L2 result has conspicuous doubled architecture. NCC brings the towers together. This is consistent with L2 being sensitive to channel brightness differences; normalizing the pixel values produces a better match here.

The difficult case: Emir

Emir remains visibly imperfect with both metrics, especially around the face, hat, and richly colored clothing. Different fabrics respond very differently to the color filters, so corresponding regions do not follow one simple brightness relationship. An incorrect estimate at a coarse scale can also persist because later levels search only nearby. Edge-based matching would be a useful next experiment, but is not included in this baseline.

Remaining artifacts

The other supplied NCC results show substantially aligned scene structure in visual inspection. Borders remain colored because the shifted exposures cover different areas. Moving foliage, water, and people can also produce local fringes that one global translation cannot remove. No numerical ground-truth offsets were available; the per-image notes describe visual inspection, not a measured accuracy score.

No bells and whistles are claimed. Automatic border detection, white balance, contrast adjustment, and more flexible transformations are possible extensions.

Reproduce the experiment

Place the supplied data folder inside proj1/. From the repository root, run:

python -m pip install -r proj1/requirements.txt
python proj1/download_extra.py
python proj1/batch.py
python proj1/build_page.py

The batch runner writes each measurement immediately to CSV and JSON. It can rerun individual groups with --groups single, --groups provided, or --groups extra, and choose metrics with --metrics ncc. Existing results for other groups and metrics are preserved. Visual review notes are maintained separately in reviews.json.
