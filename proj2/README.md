# Project 2

Open `index.html` for the Part 1.1 report. Edit this plain HTML file directly.

With NumPy, SciPy, and Pillow installed, run from the repository root:

```sh
python proj2/run_part11.py
```

The script loads `inputs/self_portrait.jpg`, checks both implementations
against SciPy, prints median runtimes over three runs and maximum errors,
and saves four images in `assets/`. It does not generate JSON, CSV, or HTML.
The webpage keeps the original measured results; update them manually if needed.
